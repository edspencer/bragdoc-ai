BragDoc keeps a record of the work you did, and the evidence for it: the screenshot of a kind message, the PDF of
a design review, the pull requests you merged, the link to the launch post. When it is time to write a self-review,
make a promotion case or update your CV, the evidence is already in one place, with dates.

It runs on your own computer. You start it with one command, open it in your browser at `http://localhost:2724`, and
everything you put in it is saved as plain Markdown and YAML files in a folder you own, `~/.bragdoc`.

:::note[Not on npm yet]
BragDoc v0.1 is built, in the open, on the [`next` branch](https://github.com/edspencer/bragdoc-ai/tree/next), but it
isn't released yet, so `npx @bragdoc/local` won't find it. These pages describe v0.1 as it is on `next`, with
screenshots of the real app. Until the release, you can run it from source: see [Contributing](/contributing/).
:::

## What it is

- **A board.** Each achievement is a card: a title, a date, a few words, and the evidence pinned to it. Cards are
  grouped by week, newest first. Drop in screenshots, PDFs, links and pull request URLs, or just type.
- **Found.** Sources you switch on (your merged GitHub pull requests, a folder of screenshots) spot things worth
  keeping and leave them in Found. You say yes, merge it into something you already have, or dismiss it. Nothing a
  source finds reaches the board without you. (Your own coding agent is the exception you choose: its writes go
  straight on, labelled as its own, or to Found if you'd rather.)
- **Folio.** Pick a date range, filter it, and take it away as Markdown (export or copy) or print it, for a review.
- **Files.** Everything is a file you can read, edit, back up or keep in git. There's no database to export from.

## What it promises

- **Your data stays on your computer.** There is no BragDoc server and no account, and BragDoc never sends your data
  to us or to anyone else: no telemetry, no analytics, no update check. The only network calls it makes are to
  services you connect yourself (in v0.1, GitHub), and it shows you every one. See
  [Network activity](/guarantees/network-activity/).
- **AI is off unless you turn it on.** v0.1 has no AI features at all; any that come later will each be off until you
  switch them on. See [AI is opt-in](/guarantees/ai-is-opt-in/).
- **It's open source.** MIT licensed, free, with nothing to buy.
