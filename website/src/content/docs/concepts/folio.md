title: Folio

---

:::note[Coming in v0.1]
Folio is being built. This page describes the design.
:::

Folio is for the moment you need it all in one place: a self-review, a promotion case, a CV update, a one-to-one.

1. **Pick a window:** this quarter, last quarter, the last six months, this year, or any dates.
2. **Filter:** by project, by company, or by minimum impact.
3. **Choose the clippings:** every matching achievement is listed; untick the ones to leave out.
4. **Read the preview:** a live Markdown document, grouped and dated, with links to the evidence.
5. **Export:** download it as a `.md` file, or copy it to paste somewhere else.

Folio doesn't write anything for you: v0.1 has no AI. It gives you the facts, in order, to write from. An optional,
opt-in drafting feature may come later; see [AI is opt-in](/guarantees/ai-is-opt-in/).
