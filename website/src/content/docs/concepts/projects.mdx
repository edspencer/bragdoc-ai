A **project** is a named piece of work with a start date, an end date (or none, if it's ongoing), a status and a
colour. An achievement can belong to any number of projects, and its card's tape takes the colour of the first.

- **Colour:** pick one of twelve swatches or any colour you like (a new project gets the next swatch in turn). The text
  on it is chosen automatically so it stays readable, and project colours look the same in the light and dark themes.
- **Status:** active, paused, done or archived. Archived projects are hidden from the timeline until you press **Show
  archived**, and the board's pickers list them under **More projects**, marked archived.
- **Company:** optional. A **company** is where you did the work, with your role and dates.
- **Repos:** optional. A **repo** is a code repository, by local path, remote URL or both. Linking repos to a project
  lets BragDoc suggest the project for pull requests from those repos. Welcome's **Your code** step can find your repos
  for you (see the [Quickstart](/getting-started/quickstart/)).

Create them on the **Projects** page with **New project** and **New company**.

## The timeline

The Projects page draws your projects as a timeline: one lane per company plus one for projects without a company,
month gridlines, a marker for today, and striped bars for projects that are still going. It opens scrolled to today.
Click a bar to see that project's pile of achievements, or a company's name to edit it. On a narrow screen the
timeline scrolls sideways inside itself.

## Renaming and deleting

Achievements refer to projects by id, not by name, so renaming a project changes one file.

Deleting a project (BragDoc asks first, and offers **Archive instead**) moves its file to `backups/removed/` and takes
it off the achievements that had it; the message that appears says how many were untagged, and **Undo** puts the
project back and re-tags them. Deleting a company or a repo works the same way: a deleted company's projects move to
the "No company" lane.

If you delete a project's file by hand instead, the achievements still refer to it. Nothing breaks: they load as
before, and Settings → Data lists the dangling references as Problems until you put the file back or tidy them up. See
[Your data is files](/concepts/your-data-is-files/).
